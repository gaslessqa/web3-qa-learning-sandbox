# Testing Tools Overview

In this lesson, you'll explore the landscape of Web3 testing tools and understand when to use each one.

## The Testing Toolbox

### 1. Foundry

Foundry is a blazing-fast, portable, and modular toolkit for Ethereum development.

**Key Features:**
- Written in Rust for maximum speed
- Tests written in Solidity
- Built-in fuzzing
- Gas snapshots and reports

```bash
# Install Foundry
curl -L https://foundry.paradigm.xyz | bash
foundryup
```

**Example Test:**
```solidity
// test/Counter.t.sol
import "forge-std/Test.sol";
import "../src/Counter.sol";

contract CounterTest is Test {
    Counter counter;

    function setUp() public {
        counter = new Counter();
    }

    function testIncrement() public {
        counter.increment();
        assertEq(counter.number(), 1);
    }

    function testFuzz_SetNumber(uint256 x) public {
        counter.setNumber(x);
        assertEq(counter.number(), x);
    }
}
```

### 2. Hardhat

Hardhat is a JavaScript-based development environment with excellent debugging.

**Key Features:**
- TypeScript support
- Console.log in Solidity
- Extensive plugin ecosystem
- Network forking

```bash
# Install Hardhat
npm install --save-dev hardhat
npx hardhat init
```

**Example Test:**
```typescript
// test/Counter.test.ts
import { expect } from "chai";
import { ethers } from "hardhat";

describe("Counter", function () {
  it("Should increment the counter", async function () {
    const Counter = await ethers.getContractFactory("Counter");
    const counter = await Counter.deploy();

    await counter.increment();
    expect(await counter.number()).to.equal(1);
  });
});
```

### 3. Comparison Table

| Feature | Foundry | Hardhat |
|---------|---------|---------|
| Language | Solidity | JavaScript/TS |
| Speed | Very Fast | Moderate |

## Security Analysis Tools

### Slither (Static Analysis)

Slither detects vulnerabilities without running code.

```bash
# Install
pip install slither-analyzer

# Run
slither ./contracts/
```

**Common Findings:**
- Reentrancy vulnerabilities
- Unused variables
- Incorrect visibility
- Missing zero-address checks

### Mythril (Symbolic Execution)

Mythril explores all possible execution paths.

```bash
# Install
pip install mythril

# Analyze
myth analyze ./contracts/Token.sol
```

## Testing Workflow

Here's a recommended testing workflow:

```
1. Unit Tests (Foundry/Hardhat)
   └── Test individual functions

2. Integration Tests
   └── Test contract interactions

3. Static Analysis (Slither)
   └── Catch common vulnerabilities

4. Fuzzing (Foundry/Echidna)
   └── Find edge cases

5. Formal Verification (Optional)
   └── Mathematical proofs
```

## Hands-On: Setting Up Foundry

Let's set up a Foundry project:

```bash
# Create new project
forge init my-first-project
cd my-first-project

# Project structure
# ├── lib/          # Dependencies
# ├── script/       # Deployment scripts
# ├── src/          # Contracts
# └── test/         # Tests

# Run tests
forge test

# Run with verbosity
forge test -vvvv
```
