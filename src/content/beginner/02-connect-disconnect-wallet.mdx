<Callout type="info">
  Wallet connection is your "login" in Web3. If this flow is flaky, everything else becomes flaky.
</Callout>

<SectionTitle>Goal</SectionTitle>
Connect and disconnect a wallet and validate the most common QA states.

<SectionTitle>QA Checklist</SectionTitle>
<Checklist
  items={[
    'Wallet not installed → show a clear install CTA',
    'User rejects connection → show “Connection cancelled” (no crash)',
    'Connected state shows truncated address and current network name',
    'Disconnect resets UI and clears cached session state',
    'Refresh restores state if session exists',
  ]}
/>

<SectionTitle>Manual Steps</SectionTitle>
<Steps
  items={[
    'Click Connect Wallet',
    'Approve in MetaMask',
    'Verify UI shows address + network',
    'Click Disconnect',
    'Refresh and verify correct state',
  ]}
/>
