<Callout type="info">
  Wallet connection is your "login" in Web3. If this flow is flaky, everything else becomes flaky.
</Callout>

<SectionTitle>Goal</SectionTitle>
Connect and disconnect a wallet and validate the most common QA states.

<SectionTitle>QA Checklist</SectionTitle>
<Checklist>
  <CheckItem>Wallet not installed → show a clear install CTA</CheckItem>
  <CheckItem>User rejects connection → show "Connection cancelled" (no crash)</CheckItem>
  <CheckItem>Connected state shows truncated address and current network name</CheckItem>
  <CheckItem>Disconnect resets UI and clears cached session state</CheckItem>
  <CheckItem>Refresh restores state if session exists</CheckItem>
</Checklist>

<SectionTitle>Manual Steps</SectionTitle>
<Steps>
  <Step>Click Connect Wallet</Step>
  <Step>Approve in MetaMask</Step>
  <Step>Verify UI shows address + network</Step>
  <Step>Click Disconnect</Step>
  <Step>Refresh and verify correct state</Step>
</Steps>
